# The four roles

You get one AI, and it plays four different characters. Which one you open matters
more than what you type into it.

| Role | File | When |
|---|---|---|
| **Tutor** | `tutor.md` | You are stuck and 20 minutes have passed |
| **Editor** | `editor.md` | Your tests pass and you want to know if the code is any good |
| **Interviewer** | `interviewer.md` | Practice. Any time. Ideally on a walk. |
| **Defend** | `defend.md` | Friday, on your milestone, before your instructor sees it |

## How to use one

Open a fresh chat. Paste the whole role file as your first message, filling in the
`[SQUARE BRACKETS]` at the top. Then talk normally.

**Start a new chat for each session.** A chat that has been running for three days has
forgotten its instructions and is quietly back to being a generic assistant.

## The one thing that ruins this

> "Just fix it for me."

If you type that, you get working code and learn nothing, and in eight weeks you will
sit in an interview unable to explain your own repository. The tutor is built to refuse
this. Do not go around it by opening a plain chat instead — you are only cheating the
one person the course is for.

## What goes in your log

Every role ends its session by printing a `SIGNAL` block. Copy it into
`logs/signal-log.md`. It takes ten seconds and it is how your instructor knows where
to spend the live hour tomorrow.
